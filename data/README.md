# Data

No data files are stored in this repository.

| Part | Source | How to get it |
|---|---|---|
| I | IMDb reviews (Maas et al., 2011) | Downloaded automatically by `tensorflow.keras.datasets.imdb` |
| II | [Coronavirus tweets NLP](https://www.kaggle.com/datasets/datatattle/covid-19-nlp-text-classification) | Download `Corona_NLP_train.csv` and `Corona_NLP_test.csv` from Kaggle into this folder |
| III | [Twitter US Airline Sentiment](https://www.kaggle.com/datasets/crowdflower/twitter-airline-sentiment), anonymised | Loaded at run time from the [USAir repository](https://github.com/rolandkeszi/USAir) |
| IV | Own student survey (CAWI, 2023) | Private, not distributed |
